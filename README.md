# Tic-Tac-Toe
LIVE : https://tic-tac-toe-skydra.vercel.app/
A browser-based Tic-Tac-Toe game for two players. Take turns placing **O** and **X**, and play again after a win or draw.

## Features

- Two-player gameplay on a 3 × 3 board
- Automatic win and draw detection
- Winner and win-count message
- **Replay** clears the board while keeping the scores
- **Start Again!** clears the board and resets the scores
- Responsive layout with animated visual effects

## Built With

- HTML
- CSS
- JavaScript

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.

You can also open the project folder in Visual Studio Code and run it with the Live Server extension.

## How to Play

1. Player O goes first. Players then take turns selecting an empty square.
2. The first player to place three matching symbols in a row, column, or diagonal wins.
3. If all nine squares are filled without a winner, the game ends in a draw.
4. Choose **Replay** to play another round or **Start Again!** to reset the scores.
